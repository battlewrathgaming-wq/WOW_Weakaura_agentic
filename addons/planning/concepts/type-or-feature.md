# CONCEPT HOME · `type or feature` — what earns a place in the registry

_A HOME is an INDEX, never a second copy (AL-26). Opened 2026-08-24 by the UI specialist, on a test
the **Addon creator** invented and applied against its own ask. **Both seats use it, so it lives
here rather than in either seat's guide.**_

## WHAT IT IS
> **A thing is a TYPE if a SECOND, UNRELATED instance already exists. One instance is a feature
> wearing a type's clothes.** — the Addon creator, `UI_INBOX.md` UI-2, 2026-08-24

It is the registry's own *"grows from USE, not from authority"* (his ruling, 2026-08-24) made
**checkable** — and cheap, because both instances have to be CITABLE.

## THE CLOSED LIST — the four rules, in the order they were found
    1  TWO INSTANCES        one is a feature. Both must be citable, file:line.
    2  A REFUSAL COUNTS     where the nearest second instance is a deliberate NOT-DOING, that is
       AGAINST              evidence the thing is a feature. ★ `promoter.lua:586` — *"There is no
                            drag-to-reorder here and there should not be"* — withdrew the roster.
    3  TWO SOURCES          our code OR the surveyed field (`prior_art_ace_field`, 230 addons).
       (UL-18)              ⟶ **A register that only recognises what we built twice can never tell
                            us what we are MISSING.** Proof: `ScrollFrame`, zero instances here,
                            load-bearing across the field, and `UL-16` names it the binding
                            constraint on every height finding this bench has.
                            ⚠ A field instance must be as citable as ours — never *"everyone does it"*.
    4  DISAGREEMENT         two instances that DISAGREE are stronger evidence than two that agree:
       BEATS AGREEMENT      agreement can be one author copying themselves; disagreement proves the
       (UL-18)              question was never settled. ★ The sourced picker: `promoter.lua` answers
                            empty with a dropdown row, `drive.lua:216` with a greyed readout.
                            ⟶ Ask *do they agree* before asking *is it a type*.

## WHAT THIS PAGE DOES NOT CLAIM
That a failing thing is worthless. **A feature is still built and still works** — it simply does not
become a UNIT other callers select. ⟶ And a citable ABSENCE (AceGUI publishes no range widget) marks
something we may have to DEFINE, which is not the same as one we already have.
