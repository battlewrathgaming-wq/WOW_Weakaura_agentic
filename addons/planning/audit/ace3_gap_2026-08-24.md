# ACE3 — THE GAP: what to use, what to borrow, what to reject

_Design architect, 2026-08-24, at Battlewrath's instruction: "survey the git for its full feature list. And
then do a gap of 'What to use, what to borrow, what to reject.' 'What they do better. What we need custom.'"
Companion to `ace3_scope_2026-08-24.md` (supply against demand, the UI specialist's) and
`prior_art_ace_field_2026-08-21.md` (how the field uses it). §1 verdicts are the ARCHITECT'S READ for
Battlewrath to consider against AI-23 — nothing here is ruled. §2–§3 are his two asks answered. §4 is the
era caveat that gates every adoption. The raw per-module feature survey is appended whole (§5), each line
traceable to file/function._

⚠⚠ **Standing gate on every USE below:** the git is SECONDARY reference; **the shipped fork copy is the fact
authority** (same rule as WeakAuras). §5(b) lists the features that postdate 3.3.5-era copies. And §580's
fork fact stands: LibStub resolution here is decided by LOAD ORDER among equal minors, so each adoption
verifies which copy actually runs.

★ **And the posture's care rule:** a USE verdict means *new code defaults to Ace, and hand-rolled code
adopts when next touched, with the reason logged* — never a migration sprint. Care, not churn.

|---|---|---|

Chunking (255-byte parts, \001..\004 control bytes, transparent reassembly), three priorities, 800 B/s throttle that halves under 20 FPS — all solved. ⚠ 3.3.5-era CTL is ~v24: no SendAddonMessageLogged/BNSendGameData; fine, we need neither. |
| **AceSerializer-3.0** | **USE** | The wire format for export/import and comms: exact float round-trip (frexp encoding), addon-channel-safe escaping, versioned markers. Replaces the serialisation half of `task_dump.lua`/`routes.lua` where they travel; a dev dump that never travels may keep its own form. |
| **AceDB-3.0** | **USE** | The half Ace is FOR, and we are the only embedder of 21 without it. Buys AP-9's two stores natively (char section + global section in one db), defaults magic (`["*"]`/`["**"]`), **defaults REMOVED at logout so SavedVariables stay minimal — AP-9/G30's storage concern, already solved**, profile propagation to namespaces, eight callbacks. Known caveat stands: profile switch destroys the pointer; consumers rebuild. ⚠ 3.3.5 copy has the classic 8 sections (no factionrealmregion/locale). |
| **AceDBOptions-3.0** | **USE (free with AceDB)** | The profile panel we would otherwise write, localised in 10 languages. |
| **AceAddon-3.0** | **USE** | Lifecycle (OnInitialize at ADDON_LOADED, OnEnable at PLAYER_LOGIN), module tree with enable/disable cascade, library embedding. Our `core.lua` hand-rolls exactly this. New surfaces default to it; existing cores adopt when touched. |
| **AceEvent-3.0** | **USE** | Event registration per object + `RegisterMessage`/`SendMessage` — an inter-addon message bus we already half-imitate through CallbackHandler in `map.lua`. Auto-unregister on disable. |
| **AceTimer-3.0** | **USE, era-checked** | Named cancellable timers, cancel-all on disable. ⚠ The 3.3.5-era implementation is the OnUpdate hash-bucket wheel: **0.1 s resolution, ONE extra arg** — not the 0.01 s C_Timer rewrite the git shows. Anything needing finer than 0.1 s or multi-arg stays ours, stated. ★ The scope's minor-1017 anomaly: NOT in the git's history (plain 9→10→…→17) nor the hurricup backport — a fork-local load-order bump. Read the shipped file. |
| **AceHook-3.0** | **USE** | Hook/RawHook/SecureHook + script variants, originals kept callable, auto-unhook on disable, refuses unsafe hooks on protected functions. `Core.lua`'s 16 hand-rolled hook sites are this. |
| **AceConsole-3.0** | **USE** | Slash registration + `GetArgs` (quote- and hyperlink-aware tokenizer) + Print. Small, no reason ours. |
| **CallbackHandler-1.0** | **USE (already do)** | The bus everything above registers through; `map.lua` already leans on it. ⚠ 2010-era dispatch is loadstring-compiled xpcall, not securecallfunction — fine on 3.3.5. |
| **AceBucket-3.0** | **REJECT for the hot path — on a capability fact, not taste** | The survey settles what the latency question could not: AceBucket's aggregation keeps **only arg1 as a table key with an occurrence count; every other argument is dropped.** Our coalescing exists to carry measured multi-arg readings on a budgeted hot path (`bucket.lua` 91, `manager.lua` 61, mancer stutter work). A lossy one-key bucket cannot hold that. BORROW nothing; ours is the residue, now with its written reason. Non-hot-path uses that genuinely only need "which arg1s, how many" may still USE it, stated per site. |
| **AceGUI-3.0** | **KEEP (already embedded)** | Widgets + Flow/List/Fill/Table + recycling. Not a saving — it's in service. The real item stays §6a's: we ship 13 of 17 widget types AceConfigDialog constructs and **ScrollFrame is missing and load-bearing** (the container exists upstream: `AceGUIContainer-ScrollFrame.lua`). |
| **AceConfig / Registry / Dialog / Cmd** | **REJECT for panes · BORROW three ideas** | An option table is not offline-checkable; `panespec`'s zones→rows→cells is, and the whole feedback loop rests on that (`hidden` as static subject set). BORROW, as ideas into panespec, cited: (1) the **width unit** (170 px base, half/double/relative) — resolution-independence with zero screen reads; (2) the **validate → error, confirm → popup** machinery shape (UL-7's popup already matches); (3) **NotifyChange** — one registry notification, open surfaces re-fetch and redraw. ⚠ AceConfigCmd (options from slash text) may earn a USE later for dev tooling — unruled. |
| **AceLocale-3.0** | REJECT for now | Single-locale product; `ui.lua`'s 6 matches are not translation. No demand. Revisit if the addon travels. |
| **AceTab-3.0** | REJECT | 2 declaring addons field-wide; no demand of ours. |
| **LibStub** | USE (already do), constrained | The constraint IS §580: load order decides among equal minors on this fork. Every adoption records which copy wins. |
| **LibSharedMedia-3.0** | **USE, and it is AP-13-adjacent** | The de-facto by-type token store on this client (font/border/background/statusbar). The token registry should SPEAK LSM — register our chosen media by name — so users swap fonts/textures the way every other addon lets them. Design-for-the-everyman. |
| **LibDataBroker-1.1** | DEFER | Launcher/feed object; nice-to-have, no current surface. |
| **LibDualSpec-1.0** | REJECT | Ascension's spec system is not stock dual-spec; wrong client assumption. |

## 2 · What they do better — worth taking even where we keep ours
- **The tedium of comms**: chunk framing, reassembly keyed by sender+distribution+prefix, fairness ring,
  FPS-aware throttle. Nobody should ever write this twice.
- **Storage hygiene**: AceDB strips values equal to defaults at logout — the file only carries what the user
  changed. That is AP-11's "emit what is useful" applied to SavedVariables, and it is free.
- **Disable discipline**: every Ace module cleans up on addon disable — events, timers, hooks, buckets.
  Our hand-rolled equivalents each re-solve this or don't.
- **Upgrade shims**: three generations of AceTimer coexist because each rewrite migrated live handles.
  The pattern (versioned in-place upgrade with migration) is worth copying in our own long-lived modules.
- **The width unit**: one number, no screen arithmetic, resolution-independence as a consequence.
- **Schema validation at registration** (AceConfigRegistry): the option table is validated before any UI
  touches it — the same posture as our build-time word validation; confirms the pattern, in their domain.

## 3 · What we need custom — the residue, now with reasons written
Confirmed from AI-23's starting list, none cut, one strengthened:
- **The offline frame model + measured text metric** (`smoke/frames.lua`, UL-1/UL-9): Ace has no headless
  anything; no equivalent exists anywhere (tooling audit).
- **panespec + layout**: a pane as DATA, checkable before the game sees it — the property the whole
  feedback loop rests on; an option table cannot give it.
- **The map coordinate space** (`coalesce`): three scalings reconciled; not Ace's domain.
- **The driver / sensor engine**: the product itself.
- **The route record + contract**: what travels and what it may name; ours by law.
- **The hot-path coalescing**: ★ no longer "if the measurement says so" — AceBucket is structurally lossy
  (arg1-only). Ours carries the arguments; the reason is now written and the measurement question is moot
  for the hot path.

## 4 · The era gate — what the git shows that 3.3.5-era copies lack (verify per adoption)

AceComm: RegisterAddonMessagePrefix calls (5.1+ client API), CTL v32 extras · AceDB: factionrealmregion,

## 5 · Raw survey (research agent, 2026-08-24) — per-module feature list from the git

### AceAddon-3.0 (MINOR 13)
- NewAddon([object,] name, [lib,...]) — create addon, optional base table, embeds listed libraries (~112)
- GetAddon(name, silent) — lookup by name, errors unless silent (~143)

- Module system: NewModule(name, [prototype], [lib,...]) (~220), GetModule(name, silent) (~197), IterateModules (~341); modules are full addons parented to the host
- SetDefaultModuleLibraries (~297), SetDefaultModuleState (~310), SetDefaultModulePrototype (~325) — defaults for subsequently created modules; prototype via metatable inheritance
- Enable/Disable (~271/~282) cascade to all modules; EnableModule/DisableModule (~293/~303); IsEnabled (~350); SetEnabledState pre-init (~337)
- EmbedLibraries/EmbedLibrary — LibStub lookup + lib:Embed(addon) (~151/~162)
- IterateAddons (~409), IterateAddonStatus (~417)

### AceEvent-3.0 (MINOR 4)
- RegisterEvent(event, [callback], [arg]) / UnregisterEvent — game events via shared "AceEvent30Frame" (~46/~51, frame ~15)

### AceTimer-3.0 (MINOR 17)
- ScheduleTimer(callback, delay, ...) one-shot, returns handle (~75); ScheduleRepeatingTimer (~103)

- Rewrite history (verified per SHA): minors ≤9 (2008-2012) OnUpdate hash-bucket wheel, 0.1s, one extra arg · minor 10 (d95ed0af, 2013-01-13) AnimationGroup rewrite, 0.01s, unlimited args, credited to Funkeh's LibTimer-1.0 · minor 17 (ea1b5ea0, 2014-10-14) C_Timer.After, WoW 6.0. Upgrade shims for oldminor <10, <13 (hashCompatTable), <17 retained.
- ★ The "~1017 minor" story is NOT in this repo's history nor the hurricup 3.3.5 backport (plain MINOR = 17) — a four-digit minor on the shipped fork copy is fork-local; read the shipped file.

### AceBucket-3.0 (MINOR 4)
- RegisterBucketEvent(event(s), interval, callback) — coalesces bursts into one callback per interval (~145); single event or table of events
- RegisterBucketMessage — same for AceEvent messages (~160); UnregisterBucket (~172), UnregisterAllBuckets (~191)
- Aggregation shape: callback receives ONE table keyed by each distinct arg1 seen, value = occurrence count; **only arg1 kept, other args dropped**; nil arg1 stored under the string "nil" (~105)
- Callback = method-name string or function; Embed supported

### AceHook-3.0 (MINOR 9)

- Refuses non-secure hooks on protected/secure functions unless flagged; createHook failsafe (~111)
- Unhook (~453), UnhookAll (~508), IsHooked → handler (~524); OnEmbedDisable auto-unhooks (~77)

### AceComm-3.0 (MINOR 14 + ChatThrottleLib v32)
